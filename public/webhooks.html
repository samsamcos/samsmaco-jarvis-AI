⚡ How to use

        

          1. Pick a site below (e.g. Gemini)

          2. Copy its Webhook URL

          3. POST to it with just: {"message":"Find cheapest flights to Amsterdam"}

          4. JARVIS opens that site, searches, and sends result to Telegram + overlay
        

        

          Example:
           curl -X POST http://192.168.0.8:8080/webhook/gemini-search -H "Content-Type: application/json" -d '{"message":"Best flights London to Amsterdam this weekend"}'

How to use in n8n

    

      


        

          
1. HTTP Request node → this webhook

          
Set method to POST, URL to your generated webhook URL.
Body (JSON):

          

{

  "message": "Find flights from London to Rome this weekend",

  "source": "n8n",

  "reply_url": "https://your-n8n.com/webhook/result"

}
          

        


        

          
2. Auth header (if you set a secret)

          
Add header: X-Webhook-Secret: your-token

        


        

          
3. Receive result in n8n

          
JARVIS sends the result back to your reply_url as a POST with:

          

{"ok":true,"result":"Flight found: LHR→FCO £87…","source":"jarvis"}
