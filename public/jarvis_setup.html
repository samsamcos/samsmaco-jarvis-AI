n8n INTEGRATION


        

          
Get active staff (HTTP Request node)

          
GEThttp://192.168.0.3:8080/api/active-staff

          
Returns JSON with current person, slot_id, tts, voice, ww_model, room.

          

        


        

          
Switch staff from n8n

          
POSThttp://192.168.0.3:8080/jarvis/webhook/{{group}}/{{staff}}

          
Use n8n expressions to fill group and staff from your workflow data.

          
// n8n HTTP Request
Method: POST
URL: http://192.168.0.3:8080/jarvis/webhook/{{ $json.group }}/{{ $json.staff_num }}
// No body needed

        


        

          
Set room from n8n

          
POSThttp://192.168.0.3:8080/webhook/{{room_number}}

          
// n8n HTTP Request
Method: POST
URL: http://192.168.0.3:8080/webhook/{{ $json.room }}

REST Command (configuration.yaml)

          
rest_command:
  jarvis_switch_staff:
    url: "http://192.168.0.3:8080/jarvis/webhook/{{ group }}/{{ staff }}"
    method: POST

  jarvis_set_room:
    url: "http://192.168.0.3:8080/webhook/{{ room }}"
    method: POST

  jarvis_new_task:
    url: "http://192.168.0.3:8080/api/jarvis-new-task"
    method: POST

automation:
  - alias: "Person enters living room"
    trigger:

        entity_id: binary_sensor.living_room_motion
        to: 'on'
    action:
      - service: rest_command.jarvis_set_room
        data:
          room: 38   # .38 = living room voice box
