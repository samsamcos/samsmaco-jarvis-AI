How Rules Work

Rules are checked in priority order (highest first) for every AI request from any page on this site.
If a rule matches, it overrides the default model selection.
job_type — set by the calling page/workflow (e.g. "coding", "recipe", "search", "chat")
keyword — matches if the user's text contains the keyword
tags — matches if the job has any of these capability tags
always — applies to every request (use as a global default)

Settings for the Client PC

Add to settings.json or environment:
{
  "LITELLM_URL":   "http://192.168.0.3:4050",
  "LITELLM_KEY":   "sk-local",
  "LITELLM_MODEL": "gemini-2.0-flash"
}
Quick test from the client PC:
curl -X POST http://192.168.0.3:4050/v1/chat/completions \
  -H "Content-Type: application/json" \
  -d '{"model":"gemini-2.0-flash",
       "messages":[{"role":"user","content":"hello"}]}'
Pollinations (free tier, no key):
curl -X POST http://192.168.0.3:4050/v1/chat/completions \
  -H "Content-Type: application/json" \
