Browser Jobs

Named browser automation tasks you can trigger via webhook, n8n, or by saying the job name in chat.
Each job opens a browser profile, navigates to a URL, runs steps, and returns the result.
Webhook: POST http://192.168.0.8:8080/webhook/job/<job-name> with {"query":"your question"}
How it works: Define a job like "gemini-jobs" with URL https://gemini.google.com/app and steps to type your query and extract the response. Then trigger it from n8n with a POST request. The result auto-appears on your overlays.

Profiles: Each job uses a browser profile (separate login session). First run opens a real browser — log in to the site, then close. Future runs reuse the saved session.
